## paper-deep-summary

Generate a structured, objective deep summary and extension plan (Markdown) for a single research paper: symbol glossary, 7 core sections (content, ideas, contributions, assumptions, boundaries, experiments & conclusions, future directions), with Obsidian `==highlights==`.

Install by copying `paper-deep-summary/` into your agent skills directory (e.g. `~/.gemini/config/skills/`). The helper CLI (`scan` / `scaffold` / `validate`) uses only the Python standard library and runs via `uv run`.
